## Write a plugin in 5 minutes (#245)
1. Make a folder `~/.local/share/kravein/plugins/<name>/` (lowercase, `-` allowed, no `_`).
2. `plugin.json`:
   ```json
   {"name": "<name>", "version": "1.0.0", "description": "…", "author": "…",
    "secrets": ["<name>_token"],
    "tools": {"<name>_lookup": "SAFE",
              "<name>_send": {"danger": "GUARDED", "outward": true, "scope": ["channel"]}}}
   ```
   Every tool must be listed here. Its class is a **floor** (the code can only ask more). `outward` = it acts outside this machine, and its grants pause in a tainted run. `scope` = what an "Always allow" is bound to (default: every argument).
3. `tools/<anything>.py`: ordinary skills (the docstring `Args:` block is the tool schema; tool names must start with a letter and be unique across Kravein):
   ```python
   from kravein import safety
   from kravein.registry import skill
   from kravein.safety import Danger, Verdict

   @skill(danger=Danger.GUARDED)
   def <name>_send(channel: str, text: str, _source: str = "local") -> str:
       """Send a message.

       Args:
           channel: Where to send it.
           text: What to send.
       """
       safety.enforce(Verdict(danger=Danger.GUARDED, reasons=[f"sends to {channel}"]),
                      f"send to '{channel}'", skill="<name>_send", source=_source,
                      targets=safety.describe_targets(f"<name>:{channel}"))
       ...
   ```
   Any state change calls `safety.enforce` itself (the `skill.unenforced` tripwire watches). Secrets come from `kravein.config.api_key("<name>_token")`.
4. Optional extras:
   - `agents/<profile>/SKILL.md`: a worker profile; list `plugin:<name>` in its `tools:`.
   - `mcp.json` `{"servers": {"x": {...}}}`: becomes the pending MCP server `<name>-x`.
   - `skills/<x>/SKILL.md`: a procedure (listed only, for now).
5. Run `kravein plugin enable <name>`: review what is listed, say y, restart Kravein. Then `kravein plugin list` / `kravein doctor`.
6. **Changing any file disables the plugin** until you run `enable` again.

The example in `tests/engine/fixtures/plugins/example/` is a complete plugin.

## Public interfaces
- Plugins (#245, v3 phase 1c; D10 easy, D9 no hooks), `kravein/plugins/`:
  - **`manifest.py`**:
    - `plugins_dir()` = `DATA_DIR/plugins`; `read_manifest` (strict; every tool declared with a danger in SAFE..CRITICAL).
    - `read_files` reads each file ONCE (no symlinks, ≤200 files, ≤2 MB each, `__pycache__` skipped). `hashes` / `total` / `compare` → changed / added / missing.
  - **`state.py`**: `CONFIG_DIR/plugins.json` (0600, flock): `{plugins: {name: {enabled, files{rel: sha256}, hash, version, enabled_at, mcp_added}}}`. Writers `pin`, `set_enabled`, `forget`: CLI only.
  - **`loader.py`**: `load_enabled(force)` runs from the end of `registry.load_skills`.
    - Each enabled plugin is re-hashed and does not load on any difference (`state: changed` + diff).
    - Each `tools/*.py` is exec'd **from the hashed bytes** (module `kravein_plugins.<name>.<mod>`) inside `registry.plugin_context`. Any exception unregisters the whole plugin (`state: error`); other plugins and Kravein carry on.
    - `status()`, `profile_texts()` (hashed SKILL.md text; `agents.profile.load_profile` / `list_profiles` use it, and a core profile always wins).
  - **`registry.plugin_context(name, tools)`**: while active, `@skill` forces category = origin = `plugin:<name>`, danger = max(code, manifest), outward / untrusted / scope from the manifest, no aliases. It refuses an undeclared tool and any existing name (core, MCP, other plugin).
    - `unregister_plugin(name)` removes only that category.
    - `is_profile_only(entry)` (MCP or plugin): not in the no-profile tool list, and `dispatch(allowed=None)` refuses it. `resolve_tools` accepts `plugin:<name>` while it is not loaded.
  - **`admin.py`**: `enable` (shows files + per-file hash + total, CODE PLUGIN warning, tools / profiles / procedures / MCP / secrets, asks once, re-hashes and refuses if anything moved, adds MCP servers as pending, pins), `disable`, `remove` (pins only, never the folder), `list_text`, `doctor_lines` (pins + hash check; never runs plugin code).
  - **Safety:**
    - `classify_command` hard-blocks (CRITICAL) any non-plain-read command naming a path inside the plugins dir (a glob too), our `plugins.json`, or run with a cwd inside the plugins dir.
    - `check_path` already refuses DATA_DIR / CONFIG_DIR writes, and the #211 read guard keeps the plugins dir unreadable to the agent.
    - Tests ban the plugin writers from skills/agents/platform/mcp code.
- MCP client (#243, v3 phase 1b), `kravein/mcp/`, on SDK `mcp==2.3.0`:
  - **`config.py`** owns `~/.config/kravein/mcp.json` (0600, flock). Shape: `servers.<name> = {transport stdio|http, command[], url, env{VAR: inherit | key:<api_keys name> | literal}, auth_key, sandbox, timeout, enabled, tools{tool: {pin, class SAFE|GUARDED|DESTRUCTIVE, outward, scope[], definition, approved_at}}}`.
    - Writers (`add_server`, `set_enabled`, `remove_server`, `record_approval`) are reached only from `kravein mcp add|list|approve|enable|disable|remove`; a test bans their import from skills/agents/platform.
    - The file sits in CONFIG_DIR, so `check_path` refuses agent writes. The agent may only `propose` a server.
  - **`pins.py`**: `pin(definition)` = sha256 of name + description + input_schema, raw and minus `_` display keys; `compare` → ok/new/changed/removed; `sanitized` caps the description at 1000, nested schema descriptions at 300, and refuses a schema over 16 KB or not an object; `diff_text`.
  - **`manager.py`** runs one asyncio loop thread. Each server's `mcp.Client(mode="auto", cache=None)` is entered in its own task.
    - No sampling, elicitation or roots callbacks. Calls go through `session.call_tool` (never `Client.call_tool`, which re-lists and resends on `HEADER_MISMATCH`); that error drops the connection so the next connect re-pins.
    - `ensure_started(wait)` / `sync` follow mcp.json's mtime and reconnect dead servers (gap 10 s). `call(server, tool, args, stop=)` polls the turn's stop flag and the timeout.
    - stdio servers are spawned only via **`platform/shell.spawn_pipe`** (env = exactly `build_env(spec.env)`, own process group, stderr to `STATE_DIR/mcp/<name>.stderr.log`, `sandbox=True` → bwrap `build_argv`). HTTP uses `streamable_http_client` with an `httpx2.AsyncClient` carrying `Authorization: Bearer <api_key(auth_key)>`.
  - **`bridge.py`** registers only approved and pin-matching tools through `registry.register_external` (`mcp__<server>__<tool>`, category `mcp:<server>`, the owner's class, outward, scope; `origin=mcp:<server>`, `untrusted_output=True`). The skill calls `safety.enforce` (target `mcp:<server>:<tool>`) before the server is reached. Results are capped at 8000 chars, framed as untrusted, and a forged closing marker is defanged.
  - **Registry.** External tools never reach the no-profile agent: `tool_declarations` skips them and `dispatch(allowed=None)` refuses them. `resolve_tools` accepts `mcp:<server>` / `mcp__s__t` even while disconnected. `Agent._refresh_external_tools` connects and re-resolves each turn, but only for a profile that names MCP. The `growth` profile lists `mcp:outreach`.
  - **`admin.py`**: `approve(name, classes, inward, scopes, yes)` connects, shows capped descriptions, a diff for changed tools and the hints labelled as a suggestion, then records. The class defaults to GUARDED, outward to yes, and scope to every argument. `list_text`, `doctor_lines` (never spawns).
  - **Tests**: `tests/engine/test_mcp.py` with the stdio mock `tests/engine/mcp_mock_server.py` (MOCK_VARIANT / MOCK_EXTRA / MOCK_LOG).
- GUARDED, grants, taint (#237, v3 phase 1a; owner ruling D4):
  - **Levels.** `Danger` is SAFE 0, MODERATE 1, **GUARDED 2**, DESTRUCTIVE 3, CRITICAL 4. Use names or ordering, never the numbers; the transport sends `danger.name`. `needs_confirmation` starts at GUARDED, and so does the `skill.unenforced` tripwire. Auto-approve (#35) and the #199 rules still check `== DESTRUCTIVE`.
  - **`@skill(scope=(...), outward=, untrusted_output=None, origin="")`.**
    - `scope` names must be parameters (a typo raises); with none declared, every non-injected argument counts, defaults included (`registry._scope_values`).
    - `untrusted_output=None` takes the category default: `registry.UNTRUSTED_CATEGORIES` = web, browser.
    - `dispatch` pushes a `safety.CallContext(tool, scope, outward, origin)` for the call (`safety.call_context` / `current_call()`). After an untrusted tool it calls `safety.mark_tainted(origin or "tool:<name>")`.
  - **Grants** live in `safety_rules.json` as `kind: "grant"`, so `list_rules`/`revoke_rule` and `/api/safety/rules` see them.
    - Fields: id, principal, tool, origin, outward, scope (for display), signature = `grant_signature(ctx)` (sha of tool + scope + origin), cap, expires_at, created_at, uses, last_used, day, day_uses.
    - Created only by `enforce` through private `_add_grant`, when the confirmer answers `ALWAYS` or `AlwaysAllow(cap<=1000, expires_in<=365 d)` to a GUARDED card that `enforce` offered. A malformed AlwaysAllow is not an approval.
    - `always_offer()` keeps `{allowed, signature}` for rules; a grant offer adds `kind: "grant"`, tool, scope and outward.
    - Matching recomputes the signature from the running call; a failed use count = no grant (fail closed).
    - Audit: `safety.grant_created`, `grant_used`, `grant_unusable` (expired / cap reached), `grant_suspended`, `rule_revoked`.
  - **enforce order.** blocked → below GUARDED allow → decline → `pre_confirmed` kwarg → declined this turn → **GUARDED grant** (not `no_auto`; needs a call context and a grant principal; not tainted+outward unless all taint comes from the grant's `origin`; under cap; not expired) → #199 rule / auto (DESTRUCTIVE) → no confirmer refuses → ask.
  - **Grant principal** = `confirmer_scope(grant_principal=)`, else the scope principal. `Agent._ask` passes `grant_principal or principal or run_principal`, so live runs, delegated children and jobs act for the owner, while #199 rules still key on `principal` only.
    - `jobs.add` stamps `principal` and `taint` from the creating run's scope (never from args).
    - `run_job` sets `Agent.grant_principal` / `initial_taint` from them.
  - **Taint.** `TurnMemory.taint` (`mark_tainted`, `taint_sources`).
    - The agent marks a tool message `untrusted: [...]` when taint grew during that call, and re-seeds each turn from the transcript (`_transcript_taint`: message marks, `UNTRUSTED_SUMMARY_MARK` on a folded summary, `initial_taint`).
    - A user message quoting `[task <id> report]` takes that task's stored taint (`_report_taint`; a lookup failure counts as tainted).
    - Background tasks store `tainted` (column added on connect); their thread note (`note_message`) and `status_text` taint the reader. A blocking delegate shares the TurnMemory.
- Model catalog + probe + snapshot (#234, v3 phase 0c), in `usage.py`:
  - **Catalog.** `models.catalog["provider:model"] = {as_of, price{input,cached?,output}, context, max_tools, tool_calling: verified|failed|untested, verified_at, probe{ok, at, step, error, latency_ms, input?, cached?, output?}, streaming, opaque_replay}`. It is read as a whole dict (ids have dots) and written only through `update_entry` → `config.update_settings`. `streaming` means "Kravein's adapter streams" (false today); `opaque_replay` is true for gemini/anthropic.
  - **One price source.** The catalog `price` wins. `models.prices` (#230) is a read-only fallback, and `models list` shows where a price came from (`price_source`).
  - **`probe(target, facade=None)`** is owner-run only (`kravein models probe <provider:model>`; a bare provider resolves to its model). It calls the provider directly, with no chain and no breaker.
    - Steps: (1) a plain answer; (2) the orchestrator's real prompt + `tools[]` (`_probe_surface`) asking for a tool call, with names checked against that set and **no skill executed**; (3) a replay of the call (opaque block included) with a synthetic result.
    - Each call is a ledger row (role `probe`). The outcome goes to the catalog: `verified` (+ `verified_at`) or `failed` with `step` + `error`. The error is an exception class + HTTP status or a code (`empty_reply`, `no_tool_call`, `unknown_tool`, `unavailable…`), never a message.
  - **`validate_role_setting(role, chain, facade=None) -> list[str]`** (empty = ok) and **`set_role_chain(role, chain)`** (validates, then writes; `None`/`[]` removes the role). These are the web picker's path. An agent role's (`orchestrator`, `worker:*`) first entry must be `verified`; other roles are checked for shape only. A hand edit of settings.json is not blocked.
  - **`doctor_warnings()`** → `kravein doctor` "Model roles". It warns when a role has <2 live entries, when a role is unknown, when a catalog entry's `as_of` is missing or >60 days old, and when a model in use (role chains + the global primary, `(global)`) is not verified. `list_report()` → `kravein models list`.
  - **Prompt-surface snapshot.** `tests/engine/test_prompt_surface.py` + `tests/engine/fixtures/prompt_surface/` hold the raw `SYSTEM_PROMPT`, each profile's purpose + instructions, and each profile's (and the no-profile) tool declarations: `include_unavailable=True`, `kravein.*` skills only. Update an intended change with `KRAVEIN_UPDATE_SNAPSHOT=1 .venv/bin/python -m pytest tests/engine/test_prompt_surface.py` and commit the fixtures; `-s` prints the token estimates (2026-11-14: orchestrator ~9.2k, system-ops ~12.3k, no profile ~14.6k).
- Endpoints + Anthropic (#231, v3 phase 0b), all in `llm.py`:
  - **Opt-in providers.** They are used only where a setting names them: `llm.provider`, `llm.provider_order`, `models.roles`, or a profile's `model:` (a profile model naming one puts it first even outside the global chain). A key alone never adds one to the chain. `LLM._all()` stays the five built-ins (`server.py` lists those). `LLM.endpoints()`, `LLM._extras()`, `LLM.known_providers()` (`Agent` validates a profile model against it).
  - **`EndpointProvider(name, spec)`** is a NovaRouter subclass: OpenAI wire, `usage_from_openai` (DeepSeek `prompt_cache_hit_tokens`), and the `_fit_tools` budget (audit `llm.<name>.tools_trimmed`).
    - Spec: `base_url`, `key` (the api_keys.json name, read by `config.api_key(name)`; env `KRAVEIN_<NAME>` / `<NAME>` wins), `model`, `max_tools`, `timeout` (45), `block_statuses` ([402, 429] → `ProviderBlocked`), `blocked_cooldown` (1800).
    - Names must match `[a-z][a-z0-9_-]{0,31}` and must not be a built-in or `anthropic`; otherwise the endpoint is skipped and `doctor` says "NOT USED".
    - Error texts are run through `_redact(text, key)`.
  - **`AnthropicProvider`** uses the `anthropic` SDK (pinned `>=2.8,<3`) with `max_retries=0` (the facade's failover is the retry).
    - Request: `beta.messages.create` with no `tool_choice` and no `temperature`. The system prompt is a text block with `cache_control` (with no system prompt, the last tool carries it).
    - Settings: `llm.anthropic_model` (default `claude-opus-5-5`), `anthropic_max_tokens` (16000), `anthropic_timeout_seconds` (60), `anthropic_effort` (unset), `anthropic_blocked_cooldown_seconds` (1800).
    - Preserved-thinking families (`claude-(opus|sonnet|haiku)-5-5`, `claude-(fable|mythos)-5-[12]`) get `thinking={"type":"adaptive","block_binding":{"prefix_mismatch_behavior":"drop_block"}}` with beta `thinking-binding-controls-2026-08-01`. Reason: Kravein's transcript is not append-only (the `[context]` tail is rebuilt each request), and new accounts get a 400 on any edit.
    - Errors: 401 → `LLMError`. 402, 429 and the 400 "credit balance" → `ProviderBlocked` (cooldown = `retry-after`, floor 30 s, when sent). `stop_reason: refusal` → `LLMError`, so the chain fails over.
    - Usage: `input = input_tokens + cache_read + cache_creation`, `cached = cache_read`.
  - **Thinking replay.** The whole reply content (thinking / redacted_thinking / text / tool_use, unchanged) rides on the first `ToolCall.signature` as `{"__anthropic__": [blocks]}`, and `agents/history.py` keeps that tag. `_to_anthropic_messages` replays it only when its tool_use ids equal the step's call ids; anything else is flattened to `[called …]` / `[result of …]` text. Gemini flattens it (not bytes) and the OpenAI wire drops it.
  - **`doctor`** prints an Anthropic block and one block per endpoint (model, URL, key present / NOT SET), never a key.
  - Example settings snippet:
    ```json
    {"llm": {"endpoints": {
        "deepseek": {"base_url": "https://api.deepseek.com/v1", "key": "deepseek_api_key", "model": "deepseek-v4.1-flash"},
        "zai": {"base_url": "https://api.z.ai/api/paas/v4", "key": "zai_api_key", "model": "glm-5.3-flash", "max_tools": 128}}},
     "models": {"roles": {
        "orchestrator": ["anthropic:claude-haiku-5-5", "deepseek:deepseek-v4.1-flash"],
        "worker:system-ops": ["deepseek:deepseek-v4.1-flash", "zai:glm-5.3-flash"],
    ```

    Keys go in `api_keys.json` (`deepseek_api_key`, `zai_api_key`, `anthropic_api_key`). The model ids above are the owner's targets and are **not probed**. "Model ids are not the catalogue": the DeepSeek / Z.ai ids and base URLs must be checked against the account before use.

A child is tagged with its owner's `run_principal`.

- Confirmation policy (`safety.py`, #35): `confirmation_policy() -> {"mode": "ask"|"decline"|"auto", "seconds_left", "default_seconds", "max_seconds"}`; `set_confirmation_mode(mode, seconds=None, *, by="")` (`auto` in memory only, default 1 h, capped 4 h, raises `ValueError` on bad input; `ask`/`decline` persist as `safety.confirmation_mode`); `disable_auto_approve(*, by="")`. `auto` covers DESTRUCTIVE from `safety.AUTO_SOURCES` (web, web-panel, voice, voice-live, cli, cli-ask) only, with a real confirmer; CRITICAL, hard refusals and the denial memory are unchanged. `allow_destructive: false` = `decline`. Audit: `safety.auto_approved`, `safety.mode_changed`, `safety.auto_expired`. `check_path` refuses writes to `settings.json`. Skills must never call the setters (pinned by `tests/engine/test_confirmation_policy.py`).
- Live voice audio I/O (`live.py`, #83): `LiveSession(observer=, confirmer=, model=, source=None, sink=None)`; default = `SoundDeviceSource`/`SoundDeviceSink` (laptop mic/speaker, unchanged). Network client: `net = NetworkAudio(); s = LiveSession(source=net, sink=net, observer=..., confirmer=...)`, run `s.run()` on a worker thread (blocking, returns tool-call count).
  - In: `net.push_input(bytes)` from any thread — PCM16 mono little-endian **16 kHz** (`SEND_SAMPLE_RATE`), any chunk size (odd trailing byte is carried; bounded 100 chunks, oldest dropped; audio pushed before connect is kept).
  - Out: `net.pull_output(timeout) -> bytes | Control.CLEAR | Control.CLOSED | None` — PCM16 mono **24 kHz** (`RECEIVE_SAMPLE_RATE`). `CLEAR` = barge-in: the client must drop audio it already buffered (uncollected audio is dropped server-side). `CLOSED` = session over. `None` = timeout. Output backlog bounded (400 chunks, oldest dropped).
  - Stop: client disconnect → `net.close()` (ends the session cleanly); `s.stop()` also closes `net`, so a reader blocked in `pull_output` always gets `CLOSED`. Run the reader as a loop until `CLOSED`; no other thread is left behind.
  - Custom backends implement `AudioSource.capture(put, astop, on_ready)` / `AudioSink.play(audio_queue, stop)` + `interrupt()`. Pinned by `tests/engine/test_live_audio.py` (fake genai client).

- Live turn hygiene (`live.py`, #97): transcripts and replies go through `clean_transcript` (strips `<ctrlNN>`/`<unusedNN>`/turn tokens, removes Devanagari/Arabic script — never displayed, never transliterated: letter-by-letter Latin turned "turn off this flashlight" into "tarn of dis flaishalaait"). - Shell safe set + "Always approve" (#199, `safety.py`): `classify_command(command, cwd=None)` first tokenizes with `shlex` (punctuation_chars, **no comment char**, newline/`$`/backtick = not parseable) and `_argv_safe` lowers a verdict to SAFE only when every segment is an allow-listed program with no executing/writing flag (`find -delete/-exec`, `sort -o`, `rg --pre`, `env CMD`, `git -c`, `uniq in out` ...), redirects go to `/dev/null`, `>&N` or a *new* file, and `cp`/`mv` target nothing that exists. Relative paths need `cwd` (run_command does not pass it yet, so they keep the old verdict; after a `cd` they are unknown again). Never lowers CRITICAL; forbidden + settings/rules-file checks run first. `cp` onto an existing target is now DESTRUCTIVE. `Verdict.signature` is set only for a DESTRUCTIVE single simple command in one of three families — `pkill|killall [-sig] NAME` (name kept; protected names/`-f` refused), `mv * DEST` over an existing owner target in $HOME, non-recursive `chmod MODE *` on owner files in $HOME (no setuid/sticky, no symlinks, no ssh/shell-startup). Rules: `safety_rules.json` in `STATE_DIR` (0600, atomic), `list_rules/add_always_rule/revoke_rule`, per principal (`browser`, `device:<id>`; passed with `confirmer_scope(..., principal=)`, inherited by nested scopes, `Agent.principal`). `enforce` applies a rule after hard refusals, decline policy, pre_confirmed and the denial memory, only for AUTO_SOURCES + attended + principal; audit `safety.rule_created/rule_approved/rule_revoked`. A Confirmer may return `safety.ALWAYS` (a plain str, only that exact value counts; any other string denies); `enforce` stores the signature it computed, never anything from the answer. Contract: `confirm_request` frame `always: {allowed, signature}`; `confirm_reply` `{decision: "approve"|"always"|"deny"}` (or legacy `approve: bool`; non-string decision = deny; `always` on a card without the offer = approve); `confirm_resolved` gains `decision` (`approve|always|deny|expired`); `GET /api/safety/rules`, `DELETE /api/safety/rules/{id}` (own principal; other's id = 404); no create endpoint; the phone path (`resolve_open`) is approve/deny only. Not applied to live voice or background tasks (no principal there). Self-review hardening: flag vetoes use `_risky_flag` (bundled short flags + long-option prefixes: `sort --out=`, `tree -ao`), unquoted leading globs and brace expansion refuse the safe set for flag-sensitive programs, the rules file goes through `_mentions_file` (name + glob + brace + parent dir like settings.json), `pkill` signatures refuse any pattern that is a substring of a protected name or starts with kravein/python (pkill is a substring regex), background-task confirmers pass `ALWAYS` through. **Write targets (PR #204 review):** `_write_findings` extracts every path a shell command writes (redirects, `cp/mv/install/ln/rsync/scp` dest + `-t`, `tee/touch/mkdir/truncate/mv` operands, `dd of=`, `curl -o`/`wget -O/-P`, through `env/nohup/...` wrappers, following `cd`) and runs each through `check_path`: blocked (Kravein dirs, protected roots) = refused, login/startup surface (autostart, systemd user, ssh, gpg, shell rc, fish) = DESTRUCTIVE with no signature; globs/braces/`$VAR` fall back to textual fragments + `_glob_surface_hit`. `systemctl --user enable|link|preset|add-wants|edit|set-default`, `systemd-run`, `crontab` (not `-l`), `enable-linger` are DESTRUCTIVE patterns. Pinned by `tests/engine/test_shell_write_targets.py` (verb x surface x new/existing). **Inline interpreter code (#206):** `_interpreter_findings` makes it DESTRUCTIVE with no Always: `python/node/ruby/perl/php/lua/julia/groovy/Rscript/ipython... -c/-e/-r`, code on stdin (no script argument, `-`, `< file`, a pipe in, heredoc/herestring), `eval`, `env -S`, awk with `system/getline/|/> file/@include/-f -/-i`, `python -m runpy|code|timeit|cProfile|pdb|...`; looked through `NAME=v`, control words (`if/then/do/{/!/time`) and `env/nohup/nice/timeout/xargs/exec -a/...` (index-based, capped at 40 wrappers = inline; commands over 20 KB ask unparsed). `sh|bash|zsh -c STRING` is judged by the inner string (recursive `classify_command`, depth 3; all-safe inner stays SAFE). Unparseable text (`$VAR`, heredoc, newline) falls back to `_unparsed_interpreter`. `_target_keys` also pulls paths out of inline code (normalised), so a declined `rm` retried via `python3 -c` is refused (#117). Pinned by `tests/engine/test_interpreter_oneliners.py` + `test_interpreter_hardening.py`. **Residue:** a script *file* (`python3 x.py`, `bash x.sh`, `python -m pytest`) keeps its verdict - its contents are not read; interpreter env vars (`NODE_OPTIONS=--eval`, `PERL5OPT`) on a script run; editors/other launchers that run code (`vim -c`, `emacs --eval`, `make -f`, `sqlite3`/`psql` shell escapes, `sed s///e`, `sed w FILE`); paths built by string concatenation inside a one-liner. Older residue: `git status/log` can run repo-configured programs (`core.fsmonitor`, textconv) from a hostile `.git/config`. Pinned by `tests/engine/test_shell_safe_set.py`, `test_safety_rules.py`.
